# Cyber Black Box audit — 19 November 2026

Audited installation: `D:\CloudBox`, based on commit `dff4d6b`. Changes remain local and uncommitted. The older Documents workspace was not modified.

## Fixes

- Windows XML normalization now retains unnamed EventData messages, named Message fields and rendered messages in the searchable summary. This addresses the missing `CBB-CHECK-002` marker for newly ingested records. Original XML bytes remain unchanged; the Windows parser records version 1.1.0. Already sealed records are not rewritten.
- Windows event IDs are classified in the context of their actual provider. Application events reusing IDs such as 104, 1102 and 4688 no longer become false log-clearing/process events; Sysmon lookalike names are excluded.
- Eight database indexes support queue selection, pending receipts, evidence ordering/correlation, archive lookups, case scope and custody lookup. Existing databases receive the indexes on startup. Regression checks preserve existing rows, immutable-table triggers and synchronous=FULL. This is a query improvement, not a measured whole-system speed guarantee; an existing large database may take longer on its first indexed startup.
- GUI data requests are cancelled when replaced, avoid overlapping interval polls, and hide stale results when switching cases/filters. A failed refresh on the same view retains the previous values with an error message.
- Copy controls no longer submit surrounding forms and handle unavailable clipboard access. Shared tabs support arrow, Home and End keyboard navigation.
- Evidence assistant case selection is explicit and uses distinguishing case labels. Malformed stored collector-health text no longer crashes the live page. Live Refresh now includes collector coverage.
- Build and acceptance scripts isolate temporary databases from inherited CBB_* configuration, avoiding accidental access to a live database/signer/witness. README identifies Docker as the simulation sender, with Kali journal collection separate.
- Release packaging includes the new isolation helper and all new regression tests.

## External validation still required

- Docker Desktop Linux engine was unavailable during this audit (daemon named pipe missing). Live Docker sender scenarios were not rerun; automated lab tests are not a substitute for a current live run.
- Live Windows collector capture, packet interfaces, Kali/WSL collection, cloud archive services, remote signing/witness services and real AI providers require their respective running services, permissions and credentials. They are not certified by isolated fixture tests.
- Existing evidence is not re-normalized. After reconnecting the Windows collector, create a fresh uniquely named test event and confirm receipt, preservation and search end to end.

No production evidence was deleted, no live collectors were started, and no changes were pushed to GitHub by this audit. Synthetic audit output is under `work/` and excluded from the release. This is a bounded audit with documented fixes and checks, not a claim that every possible defect has been eliminated.
