# Project audit — 11 November 2026

Project: Cyber Black Box. Editable source is saved in `C:\Users\PC Tecnologies\Documents\ChatGPT\cloud box`.

## Fixes and evidence

- Malformed event severity values (null, objects, lists, invalid strings) could throw during sealing and block subsequent events. Normalization now preserves original bytes, marks parse errors, and uses a fallback severity. Unexpected parser type/overflow errors quarantine the affected receipt so later records can proceed.
- JSON exponent overflow and unpaired Unicode surrogates could pass input parsing and fail later. Strict JSON parsing now rejects these values; API JSON is also checked for canonical encodability before reaching handlers, including requests with omitted content types or application/*+json media types. Binary artifact chunks remain opaque bytes.
- Case creation/update, collector configuration, evidence selections and acquisition enums had unchecked input types. These now return client validation errors for the corrected paths. Malformed MFA secrets return 422; valid MFA enrollment remains tested.
- Corrupt raw wrappers now return an integrity conflict instead of an unhandled server error. Out-of-range timestamp conversion is handled. XML DTD rejection in normalization preserves the raw observation with a parse-error flag. Malformed journal timestamp types no longer crash the importer.
- The installed pnpm 11 ignored pnpm 10's esbuild permission and prevented test/build commands. The workspace now permits only esbuild using the settings supported by both versions, and package.json records the CI version, pnpm 10.20.0. The Docker build copies this policy before installing dependencies.
- Dependency audit found five advisories in the Vitest 3 test-tool tree (two critical, three moderate). Updated Vitest to 4.1.12 and refreshed the lockfile; the subsequent pnpm audit reports no known vulnerabilities.
- Docker build context now excludes local sensor data/credentials, pnpm caches, and environment-specific dotenv files. The Windows demo link in README is repaired.
